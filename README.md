# Adjective Bloom

A one-page educational game for matching opposite personality adjectives.

Live game: https://adjective-bloom-game.fav2374.chatgpt.site

## Features

- 14 adjective pairs
- drag-and-drop Polaroid and envelope matching
- growing peony reward
- custom quill cursor and animated envelope interaction
- background music and volume control
- responsive single-screen layout

Built with React, TypeScript and Vinext.
